# 陈家乐 · 个人作品集

一个基于原生 HTML / CSS / JavaScript 的单页个人作品集网站，用于展示个人项目作品、技能方向与联系方式，支持桌面端与移动端访问。

## 技术栈

- **HTML5** — 单页语义化结构
- **CSS3** — CSS 变量驱动的主题系统，响应式布局
- **原生 JavaScript（ES5+）** — 无框架、无第三方 UI 组件库
- **IntersectionObserver** — 滚动淡入动画、导航章节高亮
- **localStorage** — 持久化用户主题偏好

## 运行方式

无需安装依赖，任选其一：

```bash
# 方式一：直接双击 index.html 用浏览器打开

# 方式二：使用任意静态服务器（推荐）
python -m http.server 8823
# 然后访问 http://localhost:8823/index.html
```

## 主要功能

- **深浅色主题切换** — 顶部导航栏右侧一键切换，背景/文字/边框颜色全局联动，`localStorage` 记住上次选择
- **项目作品展示** — 由 `js/data.js` 数据驱动渲染，含项目配图、分类、时间、技术标签，实时统计项目数量
- **技能方向展示** — 分组渲染技能标签
- **锚点导航 + 章节高亮** — 滚动时顶部导航自动高亮当前所在章节
- **滚动淡入动画** — 元素进入视口时渐显
- **响应式适配** — 移动端收纳为汉堡菜单，兼容桌面端与手机浏览
